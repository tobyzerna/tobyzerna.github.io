Task 1 · Module 9 · Interactive plot

Make it interactive!

Posted October 27, 2026

Data Visualisation Interactivity Python

Overview

I made my Module 8 map of median house prices across Australia's eight capital cities interactive using a hover function for the plots and filter for the legend.

Interactive Design Choice

The interactive feature I will add is a hover function that shows the price of when you hover over the city, so the map isn’t as cluttered. Yi et al. (2007) calls this interaction technique Abstract/Elaborate. The legend click is a Filter interaction, letting the viewer focus on one price class, while minimising complication.

Task 2 · Module 10 · Multiplot

Multiplot it!

Posted October 27th, 2026

Data Visualisation Interactivity Python

Overview

For Module 10 I extended my Module 9 map with a slider that moves between June 2016, June 2021 and June 2026. As the slider moves, the circles change colour to show how the median house price in each capital city changed over ten years. It is built in Python with Plotly.

Multiplot Visualisation

Interactive map hosted on Posit Connect Cloud.
