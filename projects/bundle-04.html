Task 1 · Module 9 · Interactive Visualisation

Interactive Map of Median House Prices

Posted [Month Day, Year]

Data Visualisation Interactivity Python

Overview

I made my Module 8 map of median house prices across Australia's eight capital cities interactive. It uses the ABS Total Value of Dwellings data for June 2026 and is built in Python with Plotly. The feedback on my Module 8 map said that using both circle size and colour for the same value added unnecessary complexity, that the legend could be simpler, and that the city coordinates could be more accurate. So I removed the size encoding, kept colour as the only encoding of price, simplified the legend and moved each city to a more accurate central point.

Interactive Design Choice

I added two interactive features. Hovering over a city shows its exact median price, and clicking an entry in the legend hides or shows every city in that price class. Hover is a details on demand interaction, which Yi et al. (2007) call Abstract/Elaborate. It let me remove the printed prices from the map, so only the city names and colours remain and the map stays clean while the exact values are still available. The legend click is a Filter interaction. It lets a viewer focus on one price class, for example only the cities over $1.3m. Both choices are intentional because the map has only eight points, so the viewer can explore it without any complicated controls.

Interactive Visualisation

Interactive map hosted on Posit Connect Cloud. Open it in a new tab.

Accessibility

Colour is the only encoding of price, so I used a ColorBrewer sequential Reds scale where a darker colour means a higher price. The legend shows the real dollar range for each class, and every city has a printed name so the map can be read without hovering. Text is dark on a light background and the exact price is available in the hover box. The embed has a descriptive title for screen readers. One limitation is that hover does not work on devices that cannot hover, which is why the names and legend are always visible.

Task 2 · Module 10 · Multiplot Display

Median House Prices Over Time

Posted [Month Day, Year]

Data Visualisation Interactivity Python

Overview

For Module 10 I extended my Module 9 map with a slider that moves between June 2016, June 2021 and June 2026, using the same ABS data. As the slider moves, the circles change colour to show how the median house price in each capital city changed over ten years. It is built in Python with Plotly.

Layout and Interactivity

The coastline, city positions and layout stay the same in every period, so only the colours change and a viewer can compare periods directly. The colour classes are fixed across all three periods, so a colour means the same price in 2016, 2021 and 2026. I used wider class breaks than in Module 9, so that the 2016 map does not show every city in the lightest colour. The slider is an Explore interaction (Yi et al., 2007), and hovering over a city shows its exact price for the selected period. With only three periods, a slider lets the viewer control the pace and switch between years rather than watching an animation.

Multiplot Visualisation

Interactive map hosted on Posit Connect Cloud.

Accessibility

As in Module 9, colour is the only encoding of price, so I used a ColorBrewer sequential Reds scale where a darker colour means a higher price. The legend shows the real dollar range for each class and every city has a printed name. The slider has labelled steps for each period, and the exact price is available in the hover box. The embed has a descriptive title for screen readers. Hover does not work on devices that cannot hover, so the colours and legend carry the main message.
